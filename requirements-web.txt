# Slim dependency set for the production web API (loom_api.web).
#
# Scope: only what POST /romanize, POST /annotate, GET /language/config/{code},
# and GET /health actually reach.  No video / no Playwright / no Streamlit /
# no OCR / no Pillow / no fonttools / no ffmpeg.
#
# Used by: Railway deploy at api.loom.nerv-analytic.ai.  Local dev devs
# install requirements.txt instead so they get the full toolchain.
#
# When adding a new language to loom_core/romanize.py, add its pip dep here
# too — otherwise Railway will 500 on the first request that exercises it.
#
# ── PINNED (2026-07-26) — versions are load-bearing, don't unpin ───────
# These were unpinned, so every deploy silently re-resolved and prod drifted
# away from every laptop.  That is how rate limiting broke: prod landed on
# fastapi 0.140, whose new `_IncludedRouter` wrapper made slowapi exempt
# EVERY request (silently — 250 req/1 IP, zero 429s), while local resolved
# 0.136 and enforced perfectly, so it was unreproducible off prod.  Pins are
# the versions verified live on 2026-07-26.
#
# Upgrading: bump deliberately, deploy, then RE-VERIFY the live behaviour
# that version could break — at minimum burst the rate limiter until it 429s
# (loom_api/ratelimit.py reads only the ASGI scope now, but the lesson is
# that a silent security-control failure looks exactly like success).
